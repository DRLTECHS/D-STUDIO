## Overview

The Media Generation feature allows you to create professional, AI-generated images and videos for your marketing campaigns without hiring photographers or videographers.

### Features

- ✅ **AI Image Generation** - Create product shots, banners, thumbnails
- ✅ **AI Video Generation** - Generate product demos, testimonials, commercials
- ✅ **Multiple AI Models** - DALL-E, Midjourney, Stable Diffusion, Runway, Synthesia
- ✅ **Platform Optimization** - Auto-format for each social media platform
- ✅ **Media Library** - Organize and reuse generated content
- ✅ **Batch Operations** - Generate multiple variations quickly

### Supported Models

#### Image Generation
- **DALL-E 3** (Recommended) - Highly detailed, realistic images
- **DALL-E 2** - Good quality, faster processing
- **Midjourney** - Artistic, high-quality results
- **Stable Diffusion** - Open-source, cost-effective

#### Video Generation
- **Runway ML** (Recommended) - Professional video generation
- **Synthesia** - AI avatar videos for testimonials
- **Descript** - Screen recording + AI editing
- **ElevenLabs** - Video with AI voiceovers

## Image Generation

### Quick Start

1. **Go to Admin Panel** → 🎨 Media Gen → Image Generator
2. **Fill Form:**
   - Select AI Model
   - Choose Image Type
   - Select Visual Style
   - Write detailed description
3. **Click Generate**
4. **Download or Add to Library**

### Image Types

#### 1. Product Shot 📸
**Best for:** E-commerce, product pages, social media

**What to write:**
```
"High-quality product photograph of [product name] on clean white background, 
professional studio lighting, 4K resolution, sharp focus, slightly angled view"
```

**Tips:**
- Use specific colors and materials
- Mention lighting setup
- Specify background
- Request specific angles

#### 2. Social Media Banner 📱
**Best for:** Facebook, LinkedIn headers, YouTube channel art

**What to write:**
```
"Professional LinkedIn banner for tech company, blue and white color scheme, 
modern design, includes laptop and abstract tech elements, 1200x630 resolution"
```

**Tips:**
- Mention exact dimensions
- Include brand colors
- Keep text areas clear
- Use modern design elements

#### 3. YouTube Thumbnail 🎬
**Best for:** Video thumbnails, YouTube shorts

**What to write:**
```
"Attention-grabbing YouTube thumbnail, bold red text saying 'NEW FEATURE', 
product screenshot, excited person's face, high contrast colors, 1280x720"
```

**Tips:**
- Use bold, contrasting colors
- Include face if possible
- Keep text minimal and readable
- Use high contrast

#### 4. Hero/Landing Page 🎨
**Best for:** Website headers, marketing pages

**What to write:**
```
"Large hero image for SaaS landing page, modern tech office, diverse team 
collaborating, blue and teal color palette, cinematic lighting, 1920x1080"
```

**Tips:**
- Describe the mood/feeling
- Mention people/diversity
- Specify layout area
- Use modern, clean aesthetics

#### 5. Infographic 📊
**Best for:** Educational content, data visualization

**What to write:**
```
"Infographic showing 5 benefits of cloud computing, icons, statistics, 
modern design, horizontal layout, business blue color scheme, clean typography"
```

**Tips:**
- Describe data hierarchy
- Mention specific sections
- Use clear icon descriptions
- Specify information flow

#### 6. Product Mockup 🖥️
**Best for:** Device mockups, app screenshots

**What to write:**
```
"iPad mockup showing D-STUDIO interface, app screenshot on realistic device, 
light studio background, angled 45 degrees, hand holding edge slightly, 4K"
```

**Tips:**
- Specify device type
- Mention angle/perspective
- Request realistic shadows
- Include context/hand

- Duration: 15-30 seconds

### Script Writing Tips

**Good Script:**
```
"Open with attention-grabber: Visual or question. 
Keep sentences short (spoken at natural pace). 
Use clear transitions between sections. 
Include specific timings for visual changes. 
End with clear call-to-action. 
Avoid technical jargon unless necessary. 
Write for speaking, not reading."
```

**Bad Script:**
```
"This product helps businesses with their digital transformation initiatives 
by leveraging cloud-native architecture for improved scalability, performance 
optimization, and comprehensive data analytics capabilities."
```

→ **Better:**
```
"Transform your business with cloud power. 
Faster. Safer. Smarter. 
Get started today."
```

### Enable Real AI Image Generation

#### Option 1: OpenAI DALL-E 3 (Recommended)

**1. Get API Key**
```
Visit: https://platform.openai.com/api/keys
Create new secret key
Copy and save securely
```

**2. Set Environment Variable**
```
OPENAI_API_KEY=sk-your-key-here
OPENAI_IMAGE_MODEL=dall-e-3
```

**3. Update Backend Code** (server.js)
```javascript
const OpenAI = require('openai');

app.post('/api/admin/generate-image', async (req, res) => {
  const openai = new OpenAI({
    apiKey: process.env.OPENAI_API_KEY,
  });

  const image = await openai.images.generate({
    model: "dall-e-3",
    prompt: req.body.prompt,
    n: 1,
    size: "1024x1024",
    quality: req.body.quality === 'ultra' ? 'hd' : 'standard',
  });

  res.json({
    ok: true,
    imageUrl: image.data[0].url,
    ...req.body
  });
});
```

**4. Install Package**
```bash
npm install openai
```

**5. Deploy**
```bash
git add .
git commit -m "Add DALL-E 3 integration"
git push origin main
```

#### Option 2: Stability AI (Stable Diffusion)

**Setup:**
```bash
npm install @stability-ai/sdk
```

**Environment:**
```
STABILITY_API_KEY=your-key-here
```

**Code:**
```javascript
const { Client, MODELS } = require("@stability-ai/sdk");

app.post('/api/admin/generate-image', async (req, res) => {
  const client = new Client({
    apiKey: process.env.STABILITY_API_KEY,
  });

  const resp = await client.textToImage({
    prompt: req.body.prompt,
    steps: req.body.quality === 'ultra' ? 50 : 30,
    width: 1024,
    height: 1024,
    seed: 0,
  });

  res.json({
    ok: true,
    imageUrl: resp.artifacts[0].base64,
    ...req.body
  });
});
```

**2. Install SDK**

**3. Environment**

**4. Backend Code**
```javascript
const Runway = require('@runwayml/sdk');

app.post('/api/admin/generate-video', async (req, res) => {
  const runway = new Runway({
    apiKey: process.env.RUNWAY_API_KEY,
  });

  const video = await runway.generateVideo({
    type: req.body.videoType,
    prompt: req.body.script,
    duration: req.body.duration,
    aspectRatio: req.body.aspect,
  });

  res.json({
    ok: true,
    videoUrl: video.url,
    processingTime: video.renderTime,
    ...req.body
  });
});
```

## Best Practices

### Image Generation

1. **Be Specific**
   - ❌ "Nice product photo"
   - ✅ "Professional product photography of laptop on oak desk, natural window lighting, shallow depth of field, 4K"

2. **Include Context**
   - Mention environment (office, outdoors, studio)
   - Specify lighting (natural, studio, dramatic)
   - Describe composition (centered, rule of thirds, close-up)

3. **Quality Settings**
   - Standard: Quick previews, social media
   - HD: Blog posts, presentations
   - Ultra: Portfolios, print materials

4. **Style Consistency**
   - Use same style across campaign
   - Match color palettes
   - Keep aspect ratio consistent

### Video Generation

1. **Script Structure**
   - Hook (first 2 seconds)
   - Problem/Solution (middle)
   - Call-to-Action (final 3 seconds)

2. **Timing**
   - 15s: Social media shorts
   - 30s: Ads, quick demos
   - 60s: Product demos, testimonials
   - 2-3m: Explainers, deep dives

3. **Voice & Music**
   - Match voice to content type
   - Use music for engagement
   - Include subtitles for accessibility

4. **Aspect Ratio**
   - 16:9 for YouTube/web
   - 9:16 for TikTok/Reels
   - 1:1 for Instagram posts

### Optimization Tips

**For Social Media:**
- ✅ Use trending colors and styles
- ✅ Include faces (increases engagement)
- ✅ Keep text readable at small sizes
- ✅ Use bold, contrasting colors

**For Web:**
- ✅ Optimize file size
- ✅ Use modern, professional styles
- ✅ Ensure readability
- ✅ Match brand guidelines

**For Print:**
- ✅ Use ultra quality setting
- ✅ 4K or higher resolution
- ✅ Professional photography style
- ✅ High contrast colors

## Troubleshooting

### Image Generation Issues

**Problem: Generation takes too long**
- Try Standard quality instead of Ultra
- Use smaller resolution
- Simplify your prompt

**Problem: Image doesn't match my description**
- Be more specific with details
- Mention style explicitly
- Describe composition clearly
- Add reference to similar styles

**Problem: Can't download image**
- Check browser storage space
- Try different browser
- Clear cache and retry
- Use incognito window

### Video Generation Issues

**Problem: Video generation times out**
- Videos take 5-20 minutes
- Use shorter duration (15-30s)
- Simplify script
- Wait longer before refreshing

**Problem: Audio is missing**
- Check "Include Background Music" checkbox
- Select voice option instead of "None"
- Try regenerating
- Check browser audio permissions

**Problem: Subtitles aren't appearing**
- Enable "Include Subtitles" checkbox
- Regenerate video
- Check video player supports subtitles

**Problem: Media library is empty**
- Generate new media first
- Check browser storage isn't full
- Try different browser
- Clear localStorage cache

### API Integration Issues

**Problem: "API key invalid" error**
- Verify key is correct
- Check environment variable name
- Regenerate new key from provider
- Ensure spaces/special characters aren't included

**Problem: "Rate limit exceeded"**
- Wait 1 minute before retrying
- Upgrade API plan
- Reduce quality setting
- Use batch processing

**Problem: "Quota exceeded"**
- Check API usage
- Upgrade account plan
- Contact support
- Set usage limits
