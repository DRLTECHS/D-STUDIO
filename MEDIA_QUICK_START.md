## 💡 Pro Tips

### Writing Better Image Descriptions

❌ **Bad:**
```
"Nice product photo"
```

✅ **Good:**
```
"Professional product photography of modern smartwatch with rose gold finish, 
angled 45 degrees on marble surface, natural window lighting, 
shallow depth of field, luxury aesthetic, high-end quality"
```

**Include:**
- Material/color details
- Lighting type (studio, natural, dramatic)
- Composition (centered, angled, close-up)
- Background (white, marble, office)
- Mood/style (professional, casual, luxury)
- Resolution/quality level

### Writing Better Video Scripts

❌ **Bad:**
```
"Video about our product showing features and benefits"
```

✅ **Good:**
```
"HOOK (0-2s): 'Tired of manual spreadsheets?'
SOLUTION (2-10s): Quick demo of dashboard entering data automatically
BENEFITS (10-20s): Display statistics: '90% faster, 0 errors'
CTA (20-30s): 'Try free at d-studio.com - no credit card needed'
Music: Upbeat tech background throughout"
```

**Include:**
- Hook/attention grabber
- Problem and solution
- Specific benefits/stats
- Clear call-to-action
- Music/voice requirements
- Visual transitions
- Timing for each section

## 🐛 Troubleshooting

### Image Generation

**Q: Image takes forever**
A: Try Standard quality instead of Ultra. Reduces time from 20min to 3min.

**Q: Image doesn't match my description**
A: Be more specific! Include style, mood, composition, lighting details.

**Q: Can't download image**
A: Refresh page. Try different browser. Check localStorage space.

### Video Generation

**Q: Video generation times out**
A: Normal! Videos take 5-20 minutes. Wait longer before refreshing.

**Q: Video has no sound**
A: Check "Include Background Music" checkbox. Regenerate.

**Q: Videos are in media library but not showing**
A: Clear browser cache. Try incognito mode.

### API Issues

**Q: "API key invalid" error**
A: Check key is correct. Regenerate new key from OpenAI.

**Q: "Rate limit exceeded"**
A: Wait 1 minute. Try again. Consider API upgrade.
